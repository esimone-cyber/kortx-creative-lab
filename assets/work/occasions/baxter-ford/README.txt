BAXTER FORD — 300 × 600 HTML5 CREATIVE

Open index.html in any modern browser. The HTML is completely self-contained: all supplied photos and the logo are embedded; there are no external fonts, scripts or asset requests.

ANIMATION
Three vehicles rotate every 5 seconds, on a continuous 15-second loop. Photos crossfade with a subtle zoom; model information and progress indicators update in sync. Rotation pauses while an ad link has keyboard focus or the browser tab is hidden. Reduced-motion preferences disable zoom and transitions.

CLICK DESTINATIONS
Each vehicle image opens its supplied vehicle URL. All other ad areas open the supplied Ford inventory results URL. Links open in a new tab.

INVENTORY
2026 Ford Bronco Sport Big Bend · 4WD · SUV
2025 Ford Escape Active · FWD · SUV
2026 Ford Maverick XL · AWD · Crew Cab

This is a feed-style creative mock using three fixed records, not a live feed connection. The supplied listing URLs describe new vehicles, so the visible creative uses neutral inventory wording. No prices, review counts, availability or used status are asserted.

TRAFFICKING
Dimensions are fixed at 300 × 600 CSS pixels, with ad.size metadata. The inventory destination is stored in window.clickTag; each vehicle has its own URL in the inventory array. Platform-specific exit tracking, size limits or ad SDK integration may require adaptation to the receiving platform.
