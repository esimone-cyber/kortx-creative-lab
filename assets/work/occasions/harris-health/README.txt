HARRIS HEALTH | 300 x 600 ANIMATED HTML AD | INTERACTIVE MAP SCREENS

Open index.html in a browser. The standalone HTML version embeds every image.

LAYOUT
The supplied 600 x 1200 Harris Health artwork displays at exactly 300 x 600,
preserving its layout, typography, colors, headline, Learn More button, and
anniversary logo. The map area is 276 x 204 at x=12, y=200. The two supplied
552 x 408 map screenshots display at 50% size. No additional address panel.

ANIMATION
- Headline lines reveal upward with staggered fades over 1.44 seconds.
- Original headline glyphs are rendered from the source artwork; no substitute font.
- The teal/navy background sweeps continuously: 10 seconds each direction.
- Headline positions, CTA, map area and anniversary logo retain the original layout.
- Reduced-motion preference displays the final headline and a static gradient.

INTERACTION
- Initially displays the first map image.
- Click the circular hamburger menu to fade to the supplied second screen.
- Click the second screen's Go to map header to fade back to the first image.
- Both transitions take 400 ms. Reduced-motion preference removes transitions.
- The menu and back controls support keyboard activation; Escape returns to map.
- Learn More, the surrounding artwork, and each location row click through to:
  https://www.harrishealth.org/locations-hh/Pages/default.aspx
- Hosts can supply window.clickTag to override the destination.

The two screens are image-based interactive panels as requested. The displayed
map zoom and geolocation graphics are part of the reference image; they do not
request geolocation or manipulate a live Google map. No video, autoplay,
external font, dependency, or map API key is used. Distances are preserved from
the supplied artwork and are not computed for the visitor.

VALIDATION
Image dimensions, local asset references, JavaScript syntax, and source image
integrity checked. Browser visual rendering was not verified in this environment.
